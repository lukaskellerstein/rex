The comment card, four ways the stripe is gone in all four — what differs is where state lives and how selection reads show the selected state back to resting
The old stripe encoded anchor state and marked selection with the same mark — and duplicated the numbered token, which already carries state in colour. Every option below fixes that: the token owns state at full strength, and selection is always a change of intensity, never a second mark. Each also names the state in words, so the meaning never rests on colour alone. C is the one being built — the screens and the System page follow it.
A · Token Cards are quiet surfaces. State lives only in the numbered token and the meta word; selection is a lighter surface, a steel border and a ring on the token.
