Widget service notes
The widget service accepts requests on a queue and writes results to the database. Each request is acknowledged before the work begins, so a crash between acknowledgement and commit is invisible to the caller.
Retries
A failed write is retried three times with no backoff, then dropped. The settings table below says 1the retry budget is three, and nothing here says which document wins.
Setting Default Notes
Retries 23 no backoff between attempts
Cache TTL 60s keyed by request id
