Retry and cache settings
The table below is the operational contract. Everything the queue does on failure is derived from it.
Setting Default Range Notes
retries 3 0–10 applied with no backoff today
cache ttl 60s 0–600s keyed by request id
dead letter off on / off not implemented
A failed write is retried, then dropped. The queue keeps no record of what was dropped.

WIDENING THE ANCHOR
Selecting text inside a structured block is the common case, and the block is often what the comment is really about. Rather than a picker mode, the composer offers the enclosing structure — walking up the DOM from the selection — and the document previews each scope as you move through it.
WHAT EACH SCOPE STORES
textquote + position
cellelement + quote + position
rowelement + opening quote
tableelement + opening quote
All four are the existing Anchor shape — no new fields. createElementAnchor() already records the opening text as the quote, which is what makes a row survive being moved.
A column is deliberately absent. It is not one element — it is a cell from every row — so there is nothing for ElementRef to point at, and a synthetic anchor would be the kind that resolves confidently to the wrong place. Comment on the table and say which column.
