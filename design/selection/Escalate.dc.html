WIDENING THE ANCHOR
Selecting text inside a structured block is the common case, and the block is often what the comment is really about. So the row offers the enclosing structure — walking up the DOM from the selection — and the document previews each scope as you move through it. Choosing one re-anchors that row and keeps its number.
WHAT EACH SCOPE STORES
textquote + position
cellelement + quote + position
rowelement + opening quote
tableelement + opening quote
All four are the existing Anchor shape — no new fields. createElementAnchor() already records the opening text as the quote, which is what makes a row survive being moved.
A column is deliberately absent. It is not one element — it is a cell from every row — so there is nothing for ElementRef to point at, and a synthetic anchor would be the kind that resolves confidently to the wrong place. Comment on the table and say which column.
