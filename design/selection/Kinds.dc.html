PDF AND DOCX — OPEN NOW, AND ANCHORABLE REX renders Markdown, HTML, PDF and DOCX, and the explorer greys neither out. Every kind above works on a DOM and never cared where the DOM came from — a PDF page and a DOCX body are picked exactly like a Markdown paragraph. Only Apply stays off for both: there is no honest source line to write a prose edit back to. A comment whose places include a PDF still applies to the Markdown beside it, and the review bar names the PDF as skipped.
In the gutter these are ordinary numbered markers. In the document, a structural or visual anchor gets a 2px outline on the element rather than a text highlight — the Custom Highlight API paints ranges, so a block anchor is an outline, not a fill.
A DECISION THIS FORCED — anchorStateFor(), now settled
It used to report moved for every resolution below layer 1: if (!resolution) return "orphaned";
if (resolution.layer === 1) return documentChanged ? "moved" : "ok";
return "moved"; Element anchors resolve at layer 3. That was fine while they were a rare fallback — but make them a primary way to comment and every table and figure comment is permanently amber, on a document nobody has touched. With the wash cards, a table-heavy review turns the whole column amber and the signal stops meaning anything.
SETTLED — no new state, no new field A layer‑3 match reports ok when the element was found by name on an unchanged document, and moved only when it was found by a positional path. resolveElement() now reports which of the two it was. Wider than the proposal, deliberately. The proposal said “via a stable id”, but create.ts prefers aria-label, data-testid, name and title over a positional path and checks each matches exactly one element. Those name the element as surely as an id does, and every inline diagram in the test corpus is keyed that way — under the literal rule this whole page would have shipped permanently amber. A path-only match keeps moved. create.ts warns that a positional path “still matches something, so the comment lands on an unrelated paragraph” — that genuinely deserves the badge.
THE ONE THAT COULD FAIL SILENTLY — AND THE FIX THAT SHIPPED A region is geometry. Redraw the chart and x/y/w/h still resolve — onto different content, reporting success. That is precisely the failure the anchor work exists to prevent, and it is the one kind here that can produce it. Built. RegionRef carries an optional fingerprint of the element's rendered content, and a mismatch on resolve reports orphaned with the comment and its quote kept. test:anchor has a case for it: a redrawn figure must orphan while its untouched neighbour still resolves. One limit stands, and create.ts records it: a raster replaced at the same URL and the same dimensions is not detected.
