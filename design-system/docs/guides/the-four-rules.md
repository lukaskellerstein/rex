# The four rules

Everything in this system follows from these. If a new component contradicts one, the component is wrong, not the rule.

## 1. Colour means state

| Colour | Token | Means |
|---|---|---|
| Steel | `--action` `#2f5da8` | The anchor resolved exactly. |
| Amber | `--moved` `#f0b429` | Re-found after the text around it changed. |
| Red | `--lost` `#d2402f` | The text is gone — or the agent can write to disk. |
| Green | `--ok` `#4a9d7a` | Resolved. Finished, not deleted. |

**Red is spent on exactly two things**: an anchor whose text is gone, and the write-capable agent. Both mean "look at this before you go on". A third meaning teaches the reviewer to ignore the first two — which is why a superseded claim is amber, not red. An old decision replaced by a new one is not a fault.

**Violet `--active` `#7a4fa3` is the one exception, and it outranks state.** The passages of the comment whose card is open are painted violet in the document. A reviewer with a card open is asking "where is this one?", not "what state is it in" — the card already says the state in words. It is a fourth colour rather than a brighter blue because the selection panel can be half-built at the same time, and its places are blue.

**Nothing ever rests on hue alone.** Every state is written in a word beside the colour that carries it.

## 2. Selection is a change of intensity, never a second mark

A card carries its state as a wash with a matching border. Selecting it deepens that same wash and brightens that same border. Hover sits between the two, on the same hue.

Three steps of one colour, never two colours. A selected card that changed hue would answer "is this the one I have open?" by destroying "what state is it in?".

## 3. The answer outranks the machinery

The agent's reply gets body text at full contrast, no border, no card, no avatar. The tool calls fold into one 30px row. The cost and duration go in a quiet meta strip. The thinking is drawn in the trace sheet and nowhere else.

An answer with its machinery threaded through it is how a reviewer stops reading answers.

The same rule decides *where* things live: an answer is about a passage, so it stays beside the passage; the machinery has nothing to do with the document being on screen, so it is the only part worth leaving the document for.

## 4. A quote never speaks in REX's voice

Newsreader appears in exactly one place — text taken out of the document under review — and nowhere else. Everything REX says is IBM Plex Sans. Everything the document says is a serif, in italic, behind a rule.

The two sit centimetres apart in the same card, and one of them is evidence. One family, one speaker.
